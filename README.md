# Connect Four Game

This is a web-based Connect Four game built with Python and Flask. It can be run in a Google Colab notebook, allowing you to play it directly in your browser.

## How to Run in Google Colab

1.  **Open a new Google Colab notebook.**

2.  **Upload the project files:**
    *   Upload `app.py`.
    *   Create a `templates` folder and upload `index.html` and `game.html` into it.
    *   Create a `static` folder and upload `style.css` and `script.js` into it.

3.  **Install the required packages:**
    In a Colab cell, run the following command to install Flask and pyngrok:
    ```
    !pip install flask pyngrok
    ```

4.  **Run the application:**
    In a new Colab cell, paste and run the following code. This will start the Flask application and create a public URL using ngrok.
    ```python
    from pyngrok import ngrok
    import threading
    import os

    # Set up ngrok authentication token if you have one
    # from getpass import getpass
    # NGROK_AUTH_TOKEN = getpass('Enter your ngrok authtoken: ')
    # ngrok.set_auth_token(NGROK_AUTH_TOKEN)

    # Start the Flask app in a separate thread
    def run_app():
        os.system("python app.py")

    thread = threading.Thread(target=run_app)
    thread.start()

    # Open a public URL to the Flask app
    public_url = ngrok.connect(5000)
    print(" * Click this link to play:", public_url)
    ```

5.  **Play the game:**
    *   Click the public URL generated by ngrok.
    *   Enter the names for Player 1 (Red) and Player 2 (White).
    *   Click "Start Game" and enjoy!

## How to Play
- The game is played on a 12x12 grid.
- Players take turns dropping their colored discs from the top into any of the twelve columns.
- The first player to form a line of four of their discs horizontally, vertically, or diagonally wins.
- If the entire grid is filled and no player has won, the game is a draw.
- Click the "New Game" button to reset the game at any time.
